# goTAI

Rede social PWA para jovens vinculados a um Dojotai da Mahikari, voltada ao acompanhamento de práticas, compartilhamento de experiências e divulgação de atividades locais.

A identidade do projeto busca transmitir espiritualidade, acolhimento e simplicidade.
