# goTAI

O goTAI é uma iniciativa do Dojotai de Campo Grande, MS. É uma rede social PWA para jovens da Mahikari, voltada ao acompanhamento de práticas, ao compartilhamento de experiências e à divulgação de atividades locais.

A identidade do projeto busca transmitir espiritualidade, acolhimento e simplicidade.

## Estado do projeto

O projeto está na fase de definição e consolidação de requisitos. O escopo funcional inicial está documentado; matriz completa de permissões, fórmula dos pódios e alguns detalhes operacionais continuam pendentes. Ainda não há implementação de produto.
